## How to use
Each exercise is self-contained: objective, prerequisites, step-by-step prompts, a deliverable, and a verification checklist. All prompts are copy-paste ready. Work in **Word for the web** with your sample documents saved in OneDrive.

## Ground rules
Copilot accelerates review; the lawyer decides. Turn on Track Changes manually before Copilot edits. Copilot cannot accept/reject changes or add comments. Verify every figure, date, and citation. Use only sanitized sample documents inside ONB's Microsoft 365 tenant.
